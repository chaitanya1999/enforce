Welcome to EnForce IDE

developed by Chaitanya V.

EnForce is a modern, VSCode-powered web IDE for Salesforce that reimagines the Developer Console. It is designed for serious development — Tailored for real-world dev work — with multi-org support, smart Apex tooling, and full control over your Salesforce codebase.

Features -

  • Connect to multiple orgs at once
  • Facilitates Apex, Aura, LWC, VF development and deployment across multiple orgs at once (using tooling API)
  • Allows creation and editing of Static Resources as well
  • Allows code comparison between orgs (right click on tabs to select for comparison)
  • Dedicated Quick Diff mode allowing to select classes/components from two orgs at once, directly showing the difference. Useful for code reviews.
  • Open lots of classes and components in BULK using Package XML (supports Quick Diff Mode as well for immediate comparison across orgs)
  • Allows to execute SOQL queries on any connected org
  • Allows to execute Anonymous Apex on any connected org
  • Global search a keyword in the entire codebase (Supports apex & visualforce as of now)
  • Allows comparing local copy of code with its org copy, say before deployment
  • Directly login to the corresponding org through an active tab by clicking on the organization name on the bottom left
  • Command Palette (Accessible using Ctrl Shift P) with shortcuts to all the features
  • Allows hiding and pinning tabs to organize open tabs better
  • And many more features - like Zen Mode , Themes, Quick open a file from Bundle(Aura/LWC), Quick open any file universally, refresh current class/component from org ... etc


How to use :


  1. Enable CORS on your org. Go to Setup > CORS > Add this website domain to CORS whitelist.
  2. Tick "Enable CORS for OAuth endpoints".
  3. Go to Org Manager tab, click Add + icon.
  4. For authentication using username, password ( + security token ) choose Auth Mode = SOAP Login and enter the details.
  5. For authentication using accessToken / session ID choose Auth Mode = Access Token. To obtain Session Id from an existing logged in session follow next step.
  6. Run the below anonymous apex script in developer console to obtain Session ID and Instance URL.

        String sessionId = userInfo.getSessionId();
    System.debug('Session id '+ UserInfo.getOrganizationId() + UserInfo.getSessionId().substring(15));
    System.debug(URL.getOrgDomainURL().toExternalForm());
  7. Test authentication via authenticate button

Please Note -

  • When dealing with tabs (save / reload) - the IDE will interact with the org to which the current active tab belongs to.
  • Actions present on the quick actions bar (top of the screen) will interact with the org selected from the dropdown.
  • The feature "Load from Selected org" will work with the org selected from the dropdown and attempt to fetch the active class/component from there.

Known Issues -

  • Some issues with keyboard shortcuts due to browser default behavior. Keyboard shortcuts work better when enforce is launched in a dedicated window using the command.
  • Code editor : tabs drag and drop doesn't works yet, instead use keyboard shortcuts.

Keyboard Shortcuts - Global

  • Ctrl + Alt + 1/2/3/4/5 = Switch across application tabs - Org Manager / Code Editor / Query Tool / Anonymous Apex / Help

Keyboard Shortcuts - Code Editor

  • Ctrl + P = Show list of open classes & components for quick switching between tabs
  • Ctrl + Shift + P = Opens the command palette with commands to every feature
  • Ctrl + Shift + U = Open any class/component universally for the selected org
  • Ctrl + B = Toggle sidebar
  • Ctrl + Shift + B = Open another file from same bundle (Aura/LWC)
  • Ctrl + S = Save code
  • Ctrl + [W / Q] = Close active tab
  • Ctrl + Shift + Q = Close all tabs
  • Alt + Z = Toggle word wrap
  • Ctrl + O = Switch to open class/component input field
  • Ctrl + [PgUp / Tab / >] = Cycle Tabs Forward
  • Ctrl + [PgDown / Shift+Tab / <] = Cycle Tabs Backwards
  • Ctrl + Shift + [PgDown/PgUp] = Reorder tabs left right
